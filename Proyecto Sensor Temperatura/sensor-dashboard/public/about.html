Acerca del Proyecto

Este sistema IoT fue desarrollado para monitorear en tiempo real la temperatura y humedad utilizando un microcontrolador ESP8266 y un sensor DHT22. Permite comunicación bidireccional (Read and Push) para accionar un LED desde un panel web.

Tecnologías utilizadas: Node.js, Express, MongoDB (NoSQL), Plotly.js y JWT para seguridad.
